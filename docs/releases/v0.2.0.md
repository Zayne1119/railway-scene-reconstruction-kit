# Railway Scene Reconstruction Kit v0.2.0

`v0.2.0` turns the initial reusable toolkit into a topology-guarded, quality-gated railway reconstruction foundation.

## Highlights

- Global TrackGraph with stable identities and fail-closed checks for broken, duplicated and mismatched rails.
- Continuous rail, sleeper and track-bed generation that consumes accepted TrackGraph geometry.
- Quality Gate v2 with immutable evidence, artifact hashes, waiver binding and release-readiness checks.
- Asset registry, evidence levels, Web acceptance mode and Blender/UE delivery checks.
- Paper Benchmark templates, open-source baseline adapters and synthetic regression tests.

## Verified locally

- Python tests: **107 / 107 passed**
- Web tests: **3 / 3 passed**
- Synthetic end-to-end smoke test: **passed**
- Synthetic output: **1 rail pair, 5 assets, 3,704 faces / 7,448 triangles**
- Repository safety scan: **0 findings**

These are software and synthetic-data checks. They are not a claim of survey-grade accuracy or automatic reconstruction performance on a new railway.

## Showcase video

The attached `railway-scene-reconstruction-kit-v0.2.0-showcase.mp4` is a 36-second synthetic concept animation. It contains no production point cloud, panorama, coordinates, customer model or real station layout.

## Public/private boundary

This release contains reusable source code, schemas, templates, synthetic contracts and documentation. Production data, exact coordinates, customer identifiers, project-specific thresholds, production meshes and internal QA evidence remain outside the repository.
