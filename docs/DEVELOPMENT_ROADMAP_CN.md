# 复用工具包后续开发路线

本路线用于继续把已经验证过的项目能力产品化。`v0.1.0` 已能跑通数据审计、分段、基础候选、参数化轨道、复核布局生成、资产注册、Mesh 审计、Web 查看和 Blender 交付脚本，但仍不是一键完成整座站场的系统。

## 开发原则

1. 新模块只接受项目配置和数据合同，不读取固定站点目录。
2. 核心源码不得出现现场坐标、固定里程、照片帧号或历史版本文件名。
3. 自动结果先写 `candidate`，经照片/专业复核后才可写 `reviewed/accepted`。
4. 证据等级与几何同时更新；不能先生成“完整模型”再补解释。
5. 每个模块必须有合成测试、运行清单、失败退出码和不可覆盖默认值。
6. 算法文件不使用 `_vNN`；版本由 Git tag、配置哈希和 run manifest 管理。

## P0：构件级照片证据与语义闭环

目标：把 `detect-linear` 输出的竖直/线缆候选变成可复核资产。

- 按 segment 局部坐标选择相邻相机；
- 使用已冻结的投影约定生成候选裁片；
- 生成联系表、俯视定位图和几何剖面；
- 提供 `catenary_mast / canopy_column / building_edge / signal_or_trackside / false_positive` 分类；
- 将复核结果导出为标准 CSV/JSON，再由 `registry-import` 写入注册表；
- 未处理候选数必须为零或有延期结论。

完成定义：合成样例与一个内部 Pilot 均能从候选 ID 追到照片、分类人、结论和注册资产。

## P1：接触网参数化生成

- 从已接受支柱、轨道中心和线缆候选生成支柱布局；
- 型号、截面、方向、腕臂侧向必须配置化；
- 接触线、承力索、吊弦分别注册；
- 观测线段与规则补全线段使用不同证据等级；
- 校验线索连续性、悬空端点、重复吊弦和错误跨轨连接；
- 输出 reviewed layout，再复用 `tube/beam/box` 网格生成器。

完成定义：每根支柱和每条线索都有稳定 ID、来源和拓扑关系；推断跨度可在 Web 中单独关闭。

## P2：站台—雨棚—立面拟合

- 站台面按里程分段拟合高程和真实边界；
- 站台安全线、盲道、端部、开口和墙体独立资产化；
- 屋面点先聚类为多个平面，再提取真实轮廓，禁止贯穿式假屋面；
- 柱、柱帽、梁和屋面建立 `supports/connects_to` 关系；
- 楼梯、电梯、栏板按通行拓扑联合重建；
- 可见立面由点云和照片解释，不可见背面保持低置信体块；
- 输出 `reviewed_scene` 布局并通过 OBJ/Blender/UE 验收。

完成定义：近景不存在明显悬空柱、屋面破片、楼梯断口、重叠面和 Z-fighting。

## P3：跨段拼接、缺口审计与资产化 GLB

- 相邻段共享端点、切向、轨顶高程和资产 ID 规则；
- 解决重叠段产生的双轨、双柱和重复屋面；
- 建立点—模型距离、未解释点和高缺口网格；
- 每个高缺口网格记录漏建、噪声、植被、范围外或数据不足结论；
- 将 asset ID 和 evidence level 嵌入 GLB 节点 `extras`；
- 验证 OBJ/FBX/GLB 的资产 ID 集合一致。

完成定义：全线运行可从分段清单复现；段界无断裂；Web 点击结果与注册表一致。

## P4：精度、性能与发布自动化

- 加入控制点、CRS、垂直基准和坐标转换链；
- 按资产类型输出 MAE/RMSE/P50/P90/P95；
- 区分展示级、运维级和施工图级声明；
- 建立大场景 LOD/Nanite/细线显示策略；
- 增加桌面端/移动端帧率、加载时间和拾取性能测试；
- 生成 release manifest、限制清单、哈希和交付包；
- CI 增加依赖漏洞、秘密扫描和合成全流程回归。

完成定义：第二个独立铁路项目可由未参与首个项目的同事依据手册跑通，才发布 `v1.0.0`。

## 新模块接口模板

每个生产模块至少满足：

```text
输入：project.json + segment_id/layout + 上游报告
输出：workspace/derived 或 workspace/exports
报告：workspace/reports/<stage>.json
注册：资产/关系变化写入 asset_registry.json
运行：workspace/manifests/<run_id>/manifest.json
默认行为：拒绝覆盖；显式 --overwrite 才允许替换同一阶段输出
状态：candidate / reviewed / accepted / rejected / superseded
测试：无现场坐标的合成数据端到端用例
```

算法精度、照片解释和专业分类的失败必须显式返回，不能用默认体块悄悄掩盖。
