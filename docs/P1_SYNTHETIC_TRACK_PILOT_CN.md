# P1 独立合成轨道验证实验

本入口完成“独立生成候选与观测—几何重测—错误检测/归因—评价—定位图”的最小闭环。默认生成 6 个数学布局，每个包含正常、断轨、错股道连接、重叠重复轨道四种版本，共 24 个开发案例。

生成器只使用通用数学参数与随机种子，不读取客户文件、生产模型或既有站场布局。候选是轨道中心线片段，观测是带噪声的数学中心线采样；它们不是完整钢轨 Mesh、LiDAR 扫描或独立测量真值。

## 一条命令运行

在工具包目录中，使用已安装项目依赖的 Python：

```powershell
python scripts/run_synthetic_track_pilot.py --output benchmarks/local/paper-topology-p1/run-v1 --seed 20260905
```

输出路径必须尚不存在。重复运行时换一个新目录，旧结果不会被覆盖。工作目录默认放在 Git 忽略的 `benchmarks/local/` 下；公开复现包另行组装，不直接发布整个本地研究目录。

## 方法与输入边界

- `synthetic_track_scene.py`：独立生成中心线几何、观测和隔离的真值。故障通过截短几何、替换候选连接或新增重复片段实现，禁止直接改审计残差。
- `synthetic_track_audit.py`：只接收 `input`；从实际坐标计算端点距离、片段重叠及观测支持，不读取布局编号、故障标签、真值文件或预置误差。
- `synthetic_track_pilot.py`：在预测完成后进行一对一匹配、统计及绘图。真值只提供给评估与绘图，图上明确区分 Truth 和 Alert。

两个模式共用端点分离与几何重叠的告警条件：

1. `local_geometry`：报告分离或重叠几何问题。
2. `topology_evidence`：保留相同告警，再根据几何可连接的替代目标及观测支持尝试区分错接原因；不会自动修改连接。

因此当前实现两组检出实体集合相同是设计结果，不是增强算法检出率提高。增强模式存在多个等距候选时检查全部候选的支持，避免用随机 ID 选择诊断；重复片段位置由两侧样本对称计算。没有观测时保持几何报警，但不强行给出证据支持的错接归因。

输入预设候选片段沿轨方向排列，并提供待验证的有向连接。本实验尚未包含未知连接恢复、道岔推理、生产轨道装配或全场景自动重建。支持支承关系、复杂拓扑与完整钢轨几何需要后续独立验证。

## 输出与评价

| 产物 | 内容 |
| --- | --- |
| `inputs/` | 24 个纯检测输入；无真值或故障类型字段 |
| `ground_truth/` | 仅供评价的故障、位置和布局分组 |
| `predictions/` | 两种方法共 48 份预测及重测值 |
| `case_results.csv`、`report.json`、`report.md` | 逐案例、逐布局、逐故障类型和汇总结果 |
| `figures/`、`overview.png` | 24 张双方法定位图及 6×4 总览 |
| `timings.json` | 一次顺序运行的耗时，不是速度优势试验 |
| `manifest.json` | 数据/预测指纹、执行源码与依赖信息、产物校验值 |

Detection 按同一受影响实体集合匹配，Diagnosis 还要求错误类型相同。重复报警只允许一次匹配，额外报警计入误报。普通断缝报警如果指出了错误连接，可在 Detection 中计为发现，但不能在 Diagnosis 中冒充原因正确。

正常关系/几何候选检查计入误报分母，报告拒判与覆盖率；远距离不相互作用的片段对不灌入分母。定位数值是命中实体后的三维标记位置差，重复错误通常覆盖一段区间，不是工程测量精度。

六个布局的派生版本按组报告，不将 24 个案例或采样点数当成独立现场数。本轮不做统计显著性、泛化或人工节时声明。

## 当前开发结果

2026-09-05，默认种子的一次实际运行得到：

| 模式 | 发现故障 | 原因判断正确 | 正常案例触警 | 正常检查误报 |
| --- | ---: | ---: | ---: | ---: |
| local_geometry | 18/18 | 12/18 | 0/6 | 0/148 |
| topology_evidence | 18/18 | 18/18 | 0/6 | 0/148 |

这些只是开发集结果。六个错接在局部模式中被指出为端点分离，增强模式进一步标记为错股道连接。当前合并了拓扑与观测两种信息，不能用此结果单独证明观测模块的贡献；P2 需要补 `local / topology-only / topology+evidence` 三组对照、困难负例及冻结后的测试。

## 验证入口

```powershell
python -m unittest tests.test_synthetic_track_scene tests.test_synthetic_track_audit tests.test_synthetic_track_pilot
```

回归覆盖生成确定性、真值隔离、真实几何变动、ID/刚体变换不变性、无证据时的处理、正常接续/交叉排除、重复报警评价、不覆盖旧输出和重复执行的产物指纹。公开真实点云的接入状态独立记录，不用本实验代替真实数据验证。
