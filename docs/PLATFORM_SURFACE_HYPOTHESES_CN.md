# 站台顶面分段拟合

`analyze-platform` 在已建立的轨道局部坐标系中搜索最外侧钢轨之外、相对轨顶高度合理的水平表面。算法先按网格检查点数与单元高程厚度，再提取连通观测组件，并按里程分段拟合高程与轨侧边界。

```powershell
railway-recon analyze-platform --project <project.json> --segment <segment-id>
```

该阶段只输出候选 JSON、候选证据图和诊断图，不生成站台 Mesh、不写资产注册表。观测间断会保留为多个区间或组件，禁止用一个平面/矩形穿过缺测区。算法同时记录被合格水平表面完整包围的内部缺口，但这些缺口可能来自楼梯、电梯、设备遮挡或点云稀疏，必须经过照片复核后才能成为正式开口。当前版本只处理最外侧钢轨之外的站台顶面；岛式站台、盲道、安全线和竖向站台墙仍需后续专项模块。
