## 1. 数据接收

- [ ] 点云为受支持 LAS/LAZ，或转换链有记录；
- [ ] 坐标单位明确；
- [ ] 点数、范围、scale/offset 合理；
- [ ] RGB、强度、GPS time 等字段含义已确认；
- [ ] 相机 CSV 至少含 index、timestamp、file、x、y、z；
- [ ] 投影所需姿态、角度单位和旋转约定已确认；
- [ ] 全景目录与 CSV 引用一致；
- [ ] 缺失照片和覆盖盲区已统计；
- [ ] CRS/EPSG 状态明确；
- [ ] 垂直基准状态明确；
- [ ] 控制点/检查点状态明确；
- [ ] 设备台账、图纸或人工复测资料状态明确；
- [ ] 输入为只读，SHA-256 和接收批次可追踪；
- [ ] 生产输入未加入 Git。

停止条件：单位未知、坐标框架冲突、轨迹与点云明显不对应、数据权限不清楚。

## 2. 项目初始化与审计

- [ ] 使用 `railway-recon init` 创建独立项目；
- [ ] `project.id` 符合命名规范；
- [ ] 配置只使用相对路径；
- [ ] `railway-recon validate` 通过；
- [ ] `railway-recon audit` 通过；

## 3. 分段与 20–50 m Pilot

- [ ] 已生成分段清单；
- [ ] 每段包围盒经人工检查；
- [ ] Pilot 长度为 20–50 m；
- [ ] Pilot 包含轨道和至少一种重要竖直/线性资产；
- [ ] Pilot 含至少一个真实难点，而非只选最干净区域；
- [ ] 已成功裁切 Pilot 且未覆盖输入；
- [ ] 已建立初始资产注册表；
- [ ] 已记录 Pilot 配置和 run manifest。

## 4. Pilot 技术门禁

### 坐标与投影

- [ ] 线路里程方向和局部坐标约定一致；
- [ ] 点云与照片在多个已知对象上对应；
- [ ] 相机投影误差已记录；
- [ ] 大坐标输出采用局部原点且保存变换。

### 轨道

- [ ] 钢轨候选连续；
- [ ] 已生成全局 TrackGraph，轨道 ID 不再使用分段局部编号；
- [ ] TrackGraph 审计为 `pass`，未复核候选没有进入 clean；
- [ ] 线路方向、坐标框架行列式和横向轨序通过门禁；
- [ ] 轨距方法和阈值已冻结；
- [ ] 轨顶高程和段界平顺；
- [ ] 轨枕与道床没有明显穿插；
- [ ] 多轨之间没有叠加或误配。

### 竖直和线性资产

- [ ] 接触网支柱、雨棚柱、建筑边缘和误检可区分；
- [ ] 照片证据进入分类流程；
- [ ] 低置信候选进入人工复核；
- [ ] 接触线、承力索和吊弦关系初步成立。

### 证据与注册表

- [ ] 每个资产有稳定 ID；
- [ ] status、evidence_level、confidence 和 sources 完整；
- [ ] 人工复核边界明确；
- [ ] Web 可区分不同证据等级；
- [ ] 候选资产未混入 clean 主模型。

## 5. 重点区精细化

- [ ] 已明确重点区边界和重点资产；

## 6. 全线扩展

- [ ] 通用阈值和铁路规则已冻结；
- [ ] 站点特例位于项目配置，不在核心源码；
- [ ] 每段生成独立 manifest 和 QA；
- [ ] 跨段 Mesh 只消费通过的 TrackGraph，不按端点距离强行拼轨；
- [ ] 全线段界连续性已检查；
- [ ] 轨道拓扑没有断裂、跨轨和重复版本；
- [ ] 接触网线索与支柱关系连续；
- [ ] 线路外侧资产按专业定性；
- [ ] 全线注册表合并后 ID 无重复；
- [ ] rejected/superseded 不进入 clean 主模型；
- [ ] candidate/evidence 图层可独立导出；
- [ ] 所有未处置候选有书面结论。

## 7. 几何与精度验收

- [ ] 核心资产报告 MAE/RMSE/P50/P90/P95 和覆盖率；
- [ ] 评价基准标为 internal_fit/control_check/其他；
- [ ] 拟合数据和独立评价数据未混用；
- [ ] 没有 CRS/垂直基准/控制时未声明绝对精度；
- [ ] 有控制时记录了转换链和检查点；
- [ ] 结果按资产类型和区段拆分；
- [ ] 异常值规则和样本数已说明。

## 8. Mesh 验收

- [ ] 非有限顶点为 0；
- [ ] 零面积/退化面为 0；
- [ ] 重复面为 0；
- [ ] 共面重叠和 Z-fighting 已清理；
- [ ] 法线、绕序和背面剔除正确；
- [ ] 轨道无断裂或叠加；
- [ ] 站台无裂缝、悬空或穿插；
- [ ] 屋面/吊顶无破片；
- [ ] 柱—梁—屋面真实接触；
- [ ] 楼梯与栏板接口正确；
- [ ] 透明材质与不透明材质分离；
- [ ] 三角面、对象、材质和边界已写入报告；
- [ ] 清理后资产 ID 未丢失。

## 9. UE/Blender 验收

- [ ] 在全新空场景导入；
- [ ] 单位、轴向和局部原点正确；
- [ ] GLB/FBX/OBJ 边界一致；
- [ ] 无闪面、黑面、大面积背面消失；
- [ ] 玻璃、接触网细线和远景显示合理；
- [ ] Nanite/LOD 按资产类型配置；
- [ ] 碰撞只用于需要资产；
- [ ] 目标设备加载、显存和帧率有记录；
- [ ] 固定六视角截图由独立 QA 复核。

## 10. Web 验收

- [ ] 默认加载当前 clean 模型；
- [ ] 模型版本、资产数和注册表一致；
- [ ] 旋转后拾取正确；
- [ ] 高亮与信息面板资产 ID 一致；
- [ ] ID、类型、状态、证据和置信度可筛选；
- [ ] 点/模型对比同坐标、同镜头、同尺度；
- [ ] candidate/evidence 图层默认策略正确；
- [ ] 桌面端和移动端通过；
- [ ] 错误加载有明确提示；
- [ ] 局域网访问遵守网络权限。

## 13. 轨道防复发专项

- [ ] 已在 Pilot 冻结轨顶高度窗、采样分辨率和方向上下文；
- [ ] 报告区分轨距、钢轨中心距、原始峰间距和规则化修正量；
- [ ] 每条轨头具有沿程横向/高程拟合和端点接缝记录；
- [ ] 轨道峰配对与轨顶高度估计使用独立配置，修改高程算法不会改变候选线数量和轨道 ID；
- [ ] 带上下文的 AABB 分段只用上下文估计方向，候选评分、拟合与输出严格限制在核心里程；
- [ ] 报告同时记录源搜索点数、核心搜索点数、核心局部范围和核心里程范围；
- [ ] 无标注参数选择只使用 outer-train 内的空间体素嵌套验证，外层留出未被反复调参；
- [ ] 验证集胜出方法另行通过生产点支撑、覆盖率和 TrackGraph 门禁，失败候选未替换生产模型；
- [ ] 四段候选已生成 `track-review-create` 独立复核包；
- [ ] 复核使用 reviewed 副本，自动候选未被原地篡改；
- [ ] TrackGraph 自动检查全部通过，人工复核状态为 accepted；
- [ ] 连续钢轨、全局相位轨枕和道床只由通过的 TrackGraph 生成；
- [ ] 所有自动接缝共识均记录原始差值、每侧修正量和冻结上限，超限接缝没有被隐藏连接；
- [ ] 0.5 m 断缝、反向段、错误轨族和重复轨道回归均通过。
