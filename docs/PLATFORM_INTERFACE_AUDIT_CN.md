# 站台空间接口审计

`audit-platform-interfaces` 在站台候选网格生成后，统一检查站台与钢轨、竖直候选、雨棚证据、接触网支柱及站牌证据之间的关系。

```powershell
railway-recon audit-platform-interfaces `
  --project <project.json> `
  --segment <segment-id>
```

默认读取同一段的站台网格构建报告、站台面报告、竖直候选报告、雨棚结构报告和 Mesh Gate。

## 核心规则

- 相邻共享截面的轨侧边界跳变超过阈值时，阻止场景合并。
- 计算站台轨侧边缘与最近钢轨中心、轨顶之间的内部关系，但在没有设计线、控制点和规范目标时不声明绝对净距合格。
- 竖直候选足迹与站台相交时，检查候选底部与站台顶面的高程偏差。
- 如果候选被分类为 `false_positive`，但其底部在容差内接触站台，则强制重新打开语义复核，不能直接删除。
- 如果右侧站台没有稳定雨棚柱或屋面证据重叠，则报告为数据缺口，不镜像另一侧雨棚。
- 只有照片证据、没有正式几何的站牌或栏杆继续保留为证据层。

该阶段只输出问题清单、候选关系图和诊断图，不移动构件、不改模型、不写资产注册表。
